# Character Pickup System Law

- 本系统遵守角色系统与数据宪法.
- 本系统只负责世界掉落物的探测 请求与交付结果跟踪 不维护背包 堆叠或装备实例.
- 仅在 Causal 路径执行 存活角色靠近且无遮挡时自动请求最近的可拾取对象.
- 获得请求只通过角色 SubmitInput 进入 ItemSystem 本系统只读 ItemSystem 已完成的对应结果.
- 来源身份与操作序号约束一次交付 对仍然有效掉落物保留最新交付处理记录 防止重复入包 掉落物失效后清理.
- 入包拒绝后按配置冷却重试 不以超时重发已经入包的获得请求.
- 网络投送由 NetworkSystem 与角色网络组件承担 本系统不包含 RPC 或具体网络逻辑.
- 初版只有一个拾取处理器 不迁移任何现有处理器.
