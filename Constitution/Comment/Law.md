# Comment Law

## 命名

- 字段程序识别用稳定的英文名称 给人阅读的元数据等用中文名称
- 具体来说 程序识别和序列化使用的字段名保持英文
- Unreal Editor等界面中面向人的字段显示名 分类名 提示和说明使用简体中文
- 面向人的文字不用逗号 使用空格断句 特殊符号使用半角字符
*C++ JSON CSV 等格式必需的语法逗号被排除于文字规则

## 文档编辑要求

- 禁止更新任何已有注释 以下要求仅对新增注释生效
- 注释必须使用简体中文
- 类 函数 枚举值以及重要成员声明的文档注释一律采用 `/** ... */` 形式
- 多行文档注释中 `/**` 与 `*/` 必须独占一行 正文每行以 `*` 开头
- 公共 API 必须包含 `@param` 与 `@return` 标签 参数描述用 Tab 对齐到同一列
- 简短的 getter 可以写成单行 `/** @return ... */`
- 逻辑性行内注释必须独占一行 写在被注释代码的正上方并保持相同缩进
- 行尾注释只允许用于补充单行语义 例如 Slate 属性链上的说明
- 待办事项统一写成 `// TODO: 描述` 禁止使用 `FIXME`
- 需要特别注意的地方写成 `// NOTE: 描述`
- 接口重写的分组用 `//~ Begin X Interface` 与 `//~ End X Interface` 配对标注
- 大区块之间用 `////` 分隔条隔开
- `.cpp` 中函数与函数之间可用 `//--------------` 横线分隔

## 代码编辑要求

- 判断的分支只允许用if/switch平铺 不用或者只用一个else;
- 一条代码必须独占一行;
- 大括号必须独占一行;
- 相邻且排版大致一致的代码视为一个段落 段落之间需要留空行;

**重要:全项目禁止出现逗号 改用空格断句 所有特殊符号要使用半角字符
