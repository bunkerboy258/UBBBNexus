# Comment Law

## 命名

- 程序标识符及序列化字段名使用稳定的英文名称
- 仅供蓝图默认值或编辑器配置面板编辑的配置字段 使用中文显示名 分类及说明元数据
- 蓝图图表内的项目自定义函数 节点标题 引脚 运行时变量和数据字段使用英文名称
- 运行时只读数据不属于配置字段 不因暴露给蓝图读取而添加中文显示名
- 图表内部函数及运行时数据按用途使用英文分类 禁止使用 BBB 分类或分类前缀
- BlueprintThreadSafeUpdateAnimation 放在函数列表根级 其它函数按实际用途分类
- 函数分类最多两级 禁止建立第三级分类 不为单个读取接口新增独立分类
- 代码注释与图表说明使用中文 说明文字不改变节点和数据标识的英文命名
- 面向人的文字不用逗号 使用空格断句 特殊符号使用半角字符
*C++ JSON CSV 等格式必需的语法逗号被排除于文字规则

## 文档编辑要求

- 以下要求仅对新增注释生效
- 注释必须使用简体中文
- 类 函数 枚举值以及重要成员声明的文档注释一律采用 `/** ... */` 形式
- 多行文档注释中 `/**` 与 `*/` 必须独占一行 正文每行以 `*` 开头
- 公共 API 必须包含 `@param` 与 `@return` 标签 参数描述用 Tab 对齐到同一列
- 简短的 getter 可以写成单行 `/** @return ... */`
- 逻辑性行内注释必须独占一行 写在被注释代码的正上方并保持相同缩进
- 行尾注释只允许用于补充单行语义 例如 Slate 属性链上的说明
- 待办事项统一写成 `// TODO: 描述` 禁止使用 `FIXME`
- 需要特别注意的地方写成 `// NOTE: 描述`
- 接口重写的分组用 `//~ Begin X Interface` 与 `//~ End X Interface` 配对标注
- 大区块之间用 `////` 分隔条隔开
- `.cpp` 中函数与函数之间可用 `//--------------` 横线分隔

## 代码编辑要求

- 判断的分支只允许用if/switch平铺 不用或者只用一个else;
- 一条代码必须独占一行;
- 大括号必须独占一行;
- 相邻且排版大致一致的代码视为一个段落 段落之间需要留空行;

**重要:全项目禁止出现逗号 改用空格断句 所有特殊符号要使用半角字符 且此规定适用于所有law.md;
**重要:law涉及物理目录规定的部分是默认忽略且不能提及law的;
