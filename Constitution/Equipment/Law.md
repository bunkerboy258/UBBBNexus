# Equipment Architecture Law

严格遵守 Constitution/Data/Law.md 与 Constitution/Network/Law.md

## 实例架构定位

- 装备实例以角色实例架构为参照，遵循一致的职责边界与组织原则；仅因底层职责和生命周期不同，省略不适用的角色专属系统与机制
- 禁止为形式一致引入无实际职责的结构

## 实例与职责

- 具体装备 Actor 是唯一运行时根 装备自主更新 持有者负责生命周期
- Catalog 位置保持不变 Base 保存当前实际复用的基座 Instance 下保存具体装备
- 禁止为了未来装备预建抽象系统 空处理器或配置层
- 具体装备只有 Parse Action Animation Network 四个系统
- 系统根只编排处理器 领域直属第一级只放领域控制根与 Law

## 数据与输入

- 运行时根只公开持有一个 RuntimeData 每个 DomainState 直接私有持有本领域 State
- 每个 State 必须有实际独立职责 禁止总 State 包装及按字段机械拆分
- 输入先进入固定槽 同类只保存最新输入 禁止历史事实队列
- 输入按 Local Mirror Shared 网络类别及输入类型两级目录分类 禁止第三级分类
- 输入解析与动作规则分责 同一动作规则只保留一份实现
- 动画通知只提交本机输入 镜像通知不得生成玩法结果

## 跨领域边界

- 角色只保留通用装备容器 选择 挂接与生命周期 不解释武器行为
- 操作直接提交装备 角色输入不包含装备选择 状态 开火 换弹或动作事实
- 装备只能通过角色定义的通用蒙太奇与相机输入贡献角色表现
- 装备不得直接修改角色黑板
- 装备只读持有角色黑板中的网络身份 输入不携带调用者声明的镜像身份
- 装备自己的 Network 系统负责状态同步 公共传输不解释具体装备状态
- 镜像还原当前状态 不重演历史 不产生发射等世界结果

## 动画与时序

- 装备更新等待角色及所需骨骼网格更新完成
- 角色 Linked Anim Layer 与装备网格动画实例保持独立
- 角色蒙太奇按固定 Slot 贡献 包内只有蒙太奇引用 不带装备来源或玩法标签
- 装备在贡献前检查当前持有关系 卸下时清除未消费输入与自身动画贡献
- 动画实例只读游戏线程发布的快照
- 配置无效 身份错误 非法输入与容量边界必须报警
