# Network Architecture Law

本项目的网络设计追求：“本机操作立即成立，其他机器尽快显示合理的当前结果”

1. **可信 P2P 合作联机**：不考虑反作弊，只要求世界适度一致，不追求逐帧、逐事件完全一致。

2. **本机执行，房主分发，远端还原**：本机操作直接成立，房主不重新裁决玩家行为，不引入预测、回滚和历史重演。

3. **当前结果优先于历史过程**：允许短暂不同步、跳过中间状态和丢弃过期表现；通信恢复后应收敛到当前有效状态。

4. **谁拥有业务，谁负责同步**：角色同步角色，装备同步装备；可以共享网络载体，但不得互相承担对方的内部语义。

5. **弱一致不等于无边界**：迟到消息不能作用于错误实例或覆盖新状态，镜像还原不能重复产生世界结果。

6. **统一规则，保持简单**：角色与装备统一架构原则和网络身份来源，底层使用 UE 同步机制；不增加无必要的包装、历史队列或通用框架。
