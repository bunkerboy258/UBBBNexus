# Character Network System Law

- 本系统是角色网络观察与发送调度的 具体逻辑 的唯一持有者
- `Character/Network/` 下的角色网络组件是 RPC 属性复制和网络接收的唯一定义持有者
- 网络系统 只能只读 已经生成的黑板状态与本帧事实 禁止参与规则判断和事实生成
- 非权威本机控制 角色向权威角色 提交既成事实;权威角色 向模拟代理分发最终状态与事实.
- 网络接收 只能构造角色输入包后调用 `SubmitInput` 
- 本项目不需要客户端预测,回滚,重演和服务端重新执行本机玩法因果 权威只做最低限度结构校验与分发.
- 禁止在 `Character/Logic/System/NetworkSystem/` 新增直属文件夹或文件
