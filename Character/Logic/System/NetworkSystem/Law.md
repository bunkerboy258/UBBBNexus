# Character Network System Law

- 本系统是角色网络观察与发送调度的唯一所有者。
- `Character/Network/` 下的角色网络组件是 RPC 属性复制和网络接收的唯一边界。
- 网络系统只观察已经生成的黑板状态与本帧事实，禁止参与玩法规则判断和事实生成。
- 非权威本机控制角色向权威提交既成事实；权威角色向模拟代理分发最终状态与事实。
- 网络接收边界只能构造角色输入包并调用 `SubmitInput`，禁止直接修改任何领域黑板。
- 禁止客户端预测、回滚、重演和服务端重新执行本机玩法因果；权威只做最低限度结构校验与分发。
- 连续最终状态使用普通属性复制，离散装备事实使用 FastArray 增量数组；两者不得混为通用消息队列。
