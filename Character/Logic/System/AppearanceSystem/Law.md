# Character Appearance System Law

本系统遵守角色系统 数据 输入与网络宪法。

- 本系统是角色全部外观语义的唯一持有者 Catalog 仅提供外侧静态资源。
- 本系统只读 ItemSystem 已成立的物品位置 不登记 移动 销毁或复制真实物品。
- 基础身体和无装备内搭来自角色配置 不属于真实物品。
- Causal 生成完整外观结果 Mirror 只还原既成事实 不重演持有或搭配决策。
- 染色与迷彩关联物品实例身份 脱下和移动位置不丢失参数。
- 整体污渍与磨损属于本领域。
- 附件暂按整套预设 国旗优先支持贴片的背心 其次支持贴片的上衣。
- 暂无合法依附条件时只隐藏 不更改物品位置 条件恢复后重新显示。
- 物品位置先成立 资源或蓝图显示失败不回写物品系统 显示采用基础回退。
- 本机请求与镜像事实均通过角色 SubmitInput 进入 ParseSystem。
- 网络观察属于 NetworkSystem RPC 与复制属于 Character/Network/。
- 蓝图只应用完整机械结果 不持有穿戴 搭配 回退或材质规则。
- 不保留独立外观组件 旧外观输入和旧同步路径。
- 系统根只负责依赖注入 栈上 Context 与固定处理器调度。
- 显示依次执行资源准备 材质维护和机械应用 写入前核对组件映射及骨骼挂点。
- 只有完整请求成功显示才记录已应用版本 显示失败通过可用组件执行基础回退 并按一秒间隔重试 同一事实的重复失败不重复报警。
- 主体与附件均携带完整机械材质结果 未变化的动态材质实例复用。
- 基础回退的裤腿只按默认基础配置准备 不依赖物品持有或重演镜像穿戴规则。
- 外观快照是可复制的纯值结果 输入与网络副本不参与本机搭配决策。
