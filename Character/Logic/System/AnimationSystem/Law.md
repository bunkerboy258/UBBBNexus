# Character Animation System Law

- Animation System 只能在 CMC 完成后由 `LateUpdate` 调用，并只消费本帧最终角色事实。
- 更新顺序固定为动画层 蒙太奇请求消费 离散动作 最终动画事实采集和动画实例发布
- 动画系统禁止生成玩法事实、修改 CMC、决定网络方向或调用具体装备行为。
- 输入系统批准的蒙太奇请求只能写入动画领域蒙太奇状态的对应固定槽位引用与待消费标记 蒙太奇处理器消费请求并交给动画实例注册
- 动画领域蒙太奇状态每个固定槽位保存一个蒙太奇引用和待消费标记 动画实例继续独占活动贡献引用与 UE 实际播放状态
- 蒙太奇处理器消费待消费标记并清空对应请求引用后 才调用动画实例固定槽位注册入口 空请求引用表示明确清除对应槽位
- 动画通知不得直接修改角色或装备状态，只能向所属领域重新提交输入。

## 目录职责
- `Context/` 当前为空 更新临时数据存放在 `DomainData/Context/`
- `DomainData/` 存放动画领域状态持有者 持久状态与更新上下文
- `Processors/` 存放动画层 蒙太奇动作事实与动画状态处理器
- `State/` 当前为空 持久状态存放在 `DomainData/States/`
- 禁止在 `Character/Logic/System/AnimationSystem/` 新增直属文件夹或文件
