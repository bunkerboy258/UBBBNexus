# Character Interaction System Law

本系统同时受角色系统 Law 与数据宪法约束.

- 本系统负责所有角色当前持有物品的交互 使用关系 挂接 卸下与单向通信.
- 本系统不维护背包 物品栏数组 快捷绑定 快捷槽位选择或背包操作.
- Causal 路径分别只读 ItemSystem 的装备主手结果与消耗品使用选择结果 并维护实际装备关系与使用关系
- 本系统不得重新解释快捷槽位规则 不得写入 ItemSystem 的领域状态.
- 装备目标变化时卸下旧装备 并挂接新的有效装备.
- 卸下真实背包装备不得销毁该物品实例 不得重置其应保留的内部状态.
- 空手目标必须解除当前装备关系.
- 实际装备结果由本系统维护 对外只读 不得以目标结果冒充实际成功结果.
- Mirror 路径根据接收的持有关系结果管理镜像装备实例.
- 镜像装备实例由本系统创建 替换与销毁 不登记到真实背包.
- 创建与挂接装备只依赖抽象装备类 公共配置及持有关系 消耗品不作为持续主手 Actor 挂接
- 装备和消耗品的内部状态由其各自内部逻辑维护 本系统不得解释其内部内容
- 只能调用装备的抽象入口 禁止依赖具体装备实现.
- 装备禁止反向调用本系统.
- 本系统可以读取执行模式 但禁止拥有具体网络逻辑.
- 禁止在 Character/Logic/System/InteractionSystem/ 新增直属文件夹或文件.

- 消耗品只能使用 使用期间保留装备关系 完成后解除使用占用和临时显示关系
- 消耗品释放 恢复生效 快速近战命中窗口和使用结束由对应通知向角色提交输入
- 消耗品的所有网格显示都通过表现通知生成
- 角色不解释引信 爆炸或装备换弹规则 只通过公开输入与物品内部逻辑通信
