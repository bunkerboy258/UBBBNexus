# Character Animation Instance Law

角色动画实例基类的职责是向角色的具体动画实例 提供经由角色控制器的主要逻辑更新之后
角色在本帧内 表现层需要用到的 基本事实和状态
基类数据只能由 AnimationSystem 一次性写入 
外部只能通过只读接口访问动画蓝图

关于蒙太奇:
- 在头文件内硬编码槽位 一个槽位只保存一个 UAnimMontage 引用 一个萝卜一个坑
- 
每个固定槽位只保存一个 UAnimMontage 引用 禁止附加播放倍率 操作序号 玩法标签 修订号 提交标记或 UE 播放状态
- 本目录无直属子目录 直属文件实现角色动画实例
- 禁止在 `Character/Animation/` 新增直属文件夹或文件
