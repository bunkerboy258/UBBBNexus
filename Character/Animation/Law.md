# Character Animation Instance Law

角色动画实例基类承载 AnimationSystem 发布的基础事实与动画领域结果 并提供必要的引擎桥接和线程安全只读接口
基类快照只能由 AnimationSystem 一次性写入
具体动画蓝图内部的派生变量由具体动画蓝图自行维护 不进入基类数据契约
不为绕转读取具体蓝图内部变量而增加原生到蓝图再返回原生的访问链
外部只能通过只读接口访问动画蓝图

- 线程安全更新入口放在函数列表根级 其余函数使用用途明确的英文分类
- 不使用 BBB 分类前缀 分类最多两级

关于蒙太奇:
- 在头文件内硬编码槽位 一个槽位只保存一个 UAnimMontage 引用 一个萝卜一个坑
- 
每个固定槽位只保存一个 UAnimMontage 引用 禁止附加播放倍率 操作序号 玩法标签 修订号 提交标记或 UE 播放状态
- 本目录无直属子目录 直属文件实现角色动画实例
- 禁止在 `Character/Animation/` 新增直属文件夹或文件
