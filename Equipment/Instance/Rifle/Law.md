# Rifle Equipment Law

- 遵守数据 装备与网络宪法
- 根只管理装配与固定更新顺序 Parse Action Animation Network
- Logic/Core 保存根本次调用的 Context 禁止跨帧持有
- Logic/RuntimeData 只保存直接持有领域 B 的 C
- Logic/System 下仅四个实际系统 不增加空系统或基类系统
- 每个系统直属第一级只保存系统控制根与 Law
- DomainData 保存 B States 保存 A Processors 保存逻辑处理器
- Parse 负责输入来源与存储 Action 按固定顺序消费输入并维护动作结果
- Animation 独占动画与音效表现 Network 独占具体状态编解码
- EmitShot 是本次唯一保留的发射扩展 默认不生成弹丸
