# Rifle Input Packet Law

- 每种包完整声明输入合法性 应用条件与应用效果
- IsValid 检查包自身 CanApply 只读上下文与事实 Apply 执行已通过的行为
- 行为状态写入必须走 RuntimeData 到 Rifle DomainState 到具体 State
- 开火的弹药 射击间隔与弹丸生成归开火包 换弹与弹匣状态变化归对应包
- 具体包可调用无状态表现处理器 处理器不得接管输入优先级或玩法裁决
- 新事实通过角色定义的事件包回传 蒙太奇与相机同样通过角色输入入口贡献
- RestoreFact 包只还原已成立事实 禁止重复生成弹丸 回报同一事实或执行本地开火裁决
- 序号 INDEX_NONE 只在已有通知输入语义中表示当前换弹 禁止扩散为通用有效序号
- 包不存储跨帧内部状态 不拥有网络逻辑 不引用玩家控制器
